## Standing rules for the day
- Keep the simulator hosts busy: when a self-play batch ends, the next one starts (new seed, or the newest teacher). Never rebuild the host (`sim/`) while a batch runs.
- Torch code runs with `.venv-learn/bin/python -I`; training reads only `data/learn/` and writes `data/learn/` and `models/`. No downloads (security review rules).
- Training never uses the benchmark's (source run, floor) pairs or exam seeds. Splits are by source run, so fights of one run never sit on both sides.
- Comparisons that decide anything are pre-registered with `templates/comparison.md` before they run (ML-10).
- Models take the visible observation only (FP-10). Each model gets a model card (`models/<name>/MODEL_CARD.md`).
- Commit and push to `overnight/2026-11-20-full-run-sim` after each milestone; never merge into master.
- Co-op stays in view: the encoder keeps a seat axis (`players`, `player_index`, teammate slots) so a co-op observation encodes without a format change.
